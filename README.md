# 二次元相册

[![auto-sync](https://github.com/Genius-Society/acg_album/actions/workflows/auto-sync.yml/badge.svg)](https://github.com/Genius-Society/acg_album/actions/workflows/auto-sync.yml?query=branch%3Amain)
[![ms](https://img.shields.io/badge/modelscope-acg__album-624aff.svg)](https://www.modelscope.cn/studios/Genius-Society/acg_album)

二次元相册是一个专为二次元爱好者设计的网页模板，提供了一个简洁而美观的前端界面，用于展示和分享二次元图片。这个模板采用了响应式设计，确保在各种设备上都能提供良好的浏览体验。用户可以轻松地将自己喜欢的二次元图片上传到这个模板中，通过精美的布局和设计，展示从经典动漫到最新热门作品的各类插画。无论是角色插画、同人作品还是动漫截图，都能在这个模板中找到合适的展示位置，让二次元爱好者能够方便地创建和分享自己的图片收藏。
